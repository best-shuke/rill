## Fixes and additions

- DNS named outbounds now follow the live proxy groups, including nested selector changes and health state. DNS no longer remains attached to independent startup groups.
- Changing a node through either selection API retires the old pooled DoH/TCP connections so subsequent DNS queries use the new outbound.
- Desktop builds include the XPro/1 H2 and WSS outbound, with verified TLS and device-key authentication. Invalid XPro nodes and unsupported UDP routes fail explicitly.
- XPro dependencies are included in the bundled license notices. Windows builds install NASM explicitly; macOS builds target macOS 13 and later.

## Downloads

- Linux: static musl binaries for x86_64 and ARM64.
- macOS: Apple Silicon, macOS 13 or later.
- Windows: x86_64 and ARM64; Wintun is embedded.

`SHA256SUMS` lists the SHA-256 of every archive. The archives include rill's license, origin notice and third-party license notices.
