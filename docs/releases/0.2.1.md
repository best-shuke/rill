## Fixes

- **Listener authentication**: a mixed / http / socks entry in `listeners:` now honours its `users:` list, as mihomo does — those users replace the global `authentication` for that listener, and `users: []` turns authentication off. In 0.2.0 and earlier the list was silently ignored, so such a listener accepted clients the config meant to keep out. Upgrade if you use per-listener `users:`.
- A `tproxy` listener with `udp: true` and no `firewall:` key loads with externally managed rules, as in mihomo, instead of failing the config. An explicit `firewall: true` is still rejected.

See [0.2.0](https://github.com/best-shuke/rill/releases/tag/v0.2.0) for the mihomo compatibility release this builds on.
