## mihomo compatibility

Configs written for mihomo now load and behave as they do there. Every change was checked against mihomo v1.19.30 on the same configs and through a mihomo server.

**Changes that affect existing configs**

- `include-all: true` takes every top-level proxy and every provider (it used to take providers only); `filter` narrows that set, several patterns can be separated by a backtick, and look-around patterns such as `^((?!港).)*$` work.
- `exclude-filter` / `exclude-type` drop static members too; an emptied group holds `empty-fallback` (default `COMPATIBLE`) instead of disappearing.
- `load-balance` without `strategy` is consistent-hashing, as in mihomo (it was round-robin). `sticky-sessions` is supported.
- A relative `-f` is taken from the current directory, and no `-f` means `<home>/config.yaml`, as in mihomo.

**Now supported**

- Provider `override:` (all mihomo keys incl. `additional-prefix`/`-suffix` and `proxy-name`), `inline` providers, and scheduled provider `health-check` (lazy by default).
- VMess over `grpc`, `h2`, `httpupgrade` and `http`; non-UUID VLESS/VMess ids (UUIDv5 mapping); `type: dns` proxies.
- `system`, `dhcp://` and `quic://` nameservers (system resolvers / DoT fallback) instead of a config error; `hosts: {name: lan}`.
- `IN-TYPE` lists, `PROCESS-*-REGEX` / `-WILDCARD` rules, `SUB-RULE,(<condition>),<block>`.
- TUN follows `sniffer:` for TLS/HTTP, and `sniff.QUIC` reads the SNI of HTTP/3 flows.
- `socks` / `redir` listeners and `redir-port`; unsupported mihomo inbounds are skipped with a warning; tproxy works with real `TPROXY` rules.
- API JSON bodies without `Content-Type`.

**Lighter and faster**

With a real 3479-rule config on the same host: 18.7 MB RSS idle and 19 MB under load (mihomo: 40 MB / 47 MB), a third of mihomo's CPU for the same 500 requests, and a 10–20 ms config check (mihomo: 30 ms). A `GEOIP` rule no longer slows startup: the country index is cached beside the database.

See CHANGELOG.md for the full list.

## Downloads

- Linux: static musl binaries for x86_64 and ARM64.
- macOS: Apple Silicon, macOS 13 or later.
- Windows: x86_64 and ARM64; Wintun is embedded.

`SHA256SUMS` lists the SHA-256 of every archive. The archives include rill's license, origin notice and third-party license notices.
